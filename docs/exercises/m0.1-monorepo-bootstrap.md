# m0.1 — Monorepo Bootstrap (Starter)

**Tujuan:** menyiapkan monorepo npm workspaces + toolchain TypeScript.
**Kondisi saat ini:** repo kosong (baru `.gitignore`).
**Yang perlu dibangun:** root `package.json` (workspaces `packages/*`,`services/*`,`frontend`), `package-lock.json`, `tsconfig.base.json` (nodenext, strict), `eslint.config.js`, `.prettierrc.json`, `.env.example`.
**Acceptance:** `npm install` sukses & me-link workspace.

## Cara Debugging
- "Cannot find module" package internal → `npm ls --workspaces`; cocokkan path `workspaces` dengan folder.
- TS: import antar-file pakai ekstensi `.ts`; **shared package harus di-build** (`npm run build:packages`) karena Node menolak type-stripping di `node_modules`.
