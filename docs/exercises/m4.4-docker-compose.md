# m4.4 — Docker Compose Orchestration (Starter)

**Tujuan:** orkestrasi 5 container tanpa race condition.
**Yang perlu dibangun:** `docker-compose.yml` — build context root, network internal, volume keypair auth, `depends_on: condition: service_healthy`, healthcheck `node -e "fetch(...)"`; hanya gateway+frontend expose port; `VITE_API_BASE_URL` sebagai build arg.
**Acceptance:** `docker compose up` dari clone bersih jalan tanpa race (uji beberapa kali); backend tak terjangkau dari host; restart auth TIDAK menginvalidasi token (volume keypair).

## Cara Debugging
- Service gagal connect padahal `up` → pakai `condition: service_healthy` (bukan `depends_on` polos).
- Frontend tak bisa panggil API → `VITE_API_BASE_URL` di-set saat build (build arg) & tetap `localhost:8080` (URL yang diakses browser, bukan `gateway:8080`).
