# m12.3 — Refresh token berotasi dan logout yang mencabut sesi (Starter)

**Tujuan:** access token pendek (15 menit) tanpa memaksa login ulang, dengan refresh token yang dirotasi dan pencurian yang terdeteksi.
**Yang perlu dibangun:** `rotateSession` dan `endSession` di `services/auth-service/src/sessions.ts`: tukar token sekali pakai secara atomik, tolak token kedaluwarsa atau dicabut, jawab `409 REFRESH_RACE` dalam jendela 10 detik, dan cabut seluruh keluarga sesi bila token lama dipakai ulang setelahnya. Di starter keduanya menjawab 501; login dan cookie sudah berjalan.
**Acceptance:** `npm test --workspace=services/auth-service` lulus (rotasi, balapan dua tab, deteksi pemakaian ulang, logout).

## Cara Debugging

- Dua request paralel sama-sama berhasil → pemeriksaan dan penandaan `rotatedAt` harus satu transaksi.
- Dua tab membuat pengguna ter-logout → bedakan pemakaian ulang dalam jendela grace (balapan wajar) dari pemakaian ulang sesudahnya (pencurian).
- Logout tidak berefek → yang dicabut adalah keluarga sesi, bukan hanya token yang dikirim.
- Jangan simpan token mentah; cari record berdasarkan hash-nya.
