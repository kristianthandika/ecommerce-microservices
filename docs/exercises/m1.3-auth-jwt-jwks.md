# m1.3 — Register/Login, JWT RS256, JWKS (Starter)

**Tujuan:** auth terdistribusi berbasis kunci publik.
**Kondisi saat ini:** auth-service baru punya health + route error demo (m1.2).
**Yang perlu dibangun:** in-memory user store, `POST /register` (bcrypt), `POST /login` (JWT RS256), keypair **load-or-generate** + persist, `kid` = JWK thumbprint, `GET /.well-known/jwks.json`, route terproteksi `/me`.
**Acceptance:** register→login→akses terproteksi→token invalid ditolak; JWK dari endpoint bisa memverifikasi token; restart TIDAK menghasilkan keypair baru.

## Cara Debugging

- `bcrypt.compare` selalu false → urutan argumen `compare(plain, hash)`.
- `invalid signature`/`signing key not found` di service lain → `export({format:'jwk'})` TIDAK memberi `kid`; sematkan `kid` sama di JWK & header JWT (`keyid`).
- Token invalid setelah restart → keypair harus di-LOAD dari file kalau sudah ada (jangan generate ulang).
