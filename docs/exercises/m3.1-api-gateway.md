# m3.1 — API Gateway Fastify (Starter)

**Tujuan:** Backend-for-Frontend, satu pintu masuk publik.
**Yang perlu dibangun:** Fastify + `@fastify/http-proxy` ke 3 service (target dari env), `@fastify/rate-limit` + `@fastify/helmet` + CORS terpusat, penerusan **X-Forwarded-For/X-Real-IP** IP klien asli (anti-spoof).
**Acceptance:** proxy benar; rate-limit & security header aktif; `req.ip` di service = IP klien asli (bukan IP gateway).

## Cara Debugging

- 502/504 → cek service target langsung (`curl :3002/health`) untuk memisahkan gateway vs service mati.
- Dua lapis rate-limit (gateway + per-service) DISENGAJA; kalau 429 tak terduga, jangan set limit per-service lebih kecil dari gateway.
