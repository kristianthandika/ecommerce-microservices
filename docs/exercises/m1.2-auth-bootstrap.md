# m1.2 — auth-service Bootstrap & Security Middleware (Starter)

**Tujuan:** pola service Express 5 production-grade.
**Yang perlu dibangun:** Express app + `helmet`,`cors`,`express-rate-limit`,`pino-http`; error handler terpusat (JSON konsisten, tanpa stack trace); middleware validasi `zod`. Manfaatkan penanganan error async bawaan Express 5 (handler `throw` langsung, tanpa try/catch).
**Acceptance:** route yang `throw` → JSON error terstruktur (bukan HTML/stack); body invalid → 400 (bukan 500); log request JSON.

## Cara Debugging
- Error tak sampai ke handler → jangan bungkus try/catch yang menelan error; Express 5 menangkap throw/reject async otomatis.
- Response HTML default → error handler harus didaftarkan PALING AKHIR.
