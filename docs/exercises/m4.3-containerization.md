# m4.3 — Containerization per Service (Starter)

**Tujuan:** image per service yang aman & ramping.
**Yang perlu dibangun:** `Dockerfile` multi-stage non-root per service (build context = ROOT repo); frontend → **nginx** (bukan Node) dengan SPA fallback; `.dockerignore`.
**Acceptance:** build dari context root; container non-root; refresh route SPA tidak 404; frontend disajikan nginx; ukuran image multi-stage < single-stage naif.

## Cara Debugging
- "module not found" saat build → context harus ROOT repo (bukan folder service).
- bcrypt native binding error runtime → jangan compile di glibc lalu jalankan di Alpine/musl; di sini semua stage Alpine + toolchain di stage build.
- `EACCES` menulis keypair → `chown` folder `keys/` ke user `node` sebelum `USER node`.
- Refresh 404 → `try_files ... /index.html` di `nginx.conf`.
