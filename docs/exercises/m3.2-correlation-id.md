# m3.2 — Correlation ID & Log Correlation (Starter)

**Tujuan:** satu request tertelusur lintas service.
**Yang perlu dibangun:** di gateway, generate/teruskan `x-correlation-id` (`genReqId` + hook), pantulkan ke response; teruskan header yang SAMA ke service di baliknya. Pastikan order-service meneruskannya ke product-service.
**Acceptance:** satu request gateway→order→product menghasilkan correlation id yang SAMA di log KETIGA service.

## Cara Debugging
- Id hilang di product (hop kedua) → order harus meneruskan header `x-correlation-id` (jangan generate baru). Cek: `docker compose logs <svc> | grep <id>` di ketiga service.
