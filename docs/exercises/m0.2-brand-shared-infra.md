# m0.2 — Brand & Shared Infrastructure (Starter)

**Tujuan:** satu logger dipakai ulang + setup brand frontend.
**Kondisi saat ini:** monorepo kosong (m0.1).
**Yang perlu dibangun:** `packages/logger` (factory pino JSON, level dari env, +correlation id helper); frontend skeleton (Vite+TS+Tailwind) dengan token brand Inixindo & aset logo → halaman placeholder.
**Acceptance:** log JSON terstruktur dari sebuah service; halaman frontend menampilkan logo & warna brand.

## Cara Debugging

- Log tidak JSON → cek `LOG_LEVEL`; pretty-print hanya via `LOG_PRETTY=true` (bukan default).
- Warna brand tidak muncul → cek `content` glob di `tailwind.config.js` mencakup `./src/**/*.{ts,tsx}`.
