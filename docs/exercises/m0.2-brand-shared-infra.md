# m0.2 — Brand & Shared Infrastructure

| Branch awal                       | Kunci jawaban                      | Waktu    | Sebelumnya | Berikutnya |
| --------------------------------- | ---------------------------------- | -------- | ---------- | ---------- |
| `starter/m0.2-brand-shared-infra` | `solution/m0.2-brand-shared-infra` | 60 menit | m0.1       | m1.1       |

## Yang akan Anda pelajari

- Membuat **paket bersama** (`packages/logger`) yang dipakai ulang semua service.
- Log terstruktur JSON dengan pino, termasuk menyensor data rahasia.
- Kerangka frontend React + Vite + Tailwind dengan warna dan logo brand.

## Kondisi awal

Hasil m0.1: monorepo dengan TypeScript, ESLint, Prettier, belum ada workspace.

```bash
git switch starter/m0.2-brand-shared-infra
npm ci
```

Di titik ini `npm test`, `npm run typecheck`, dan `npm run build:packages` masih
menjawab `No workspaces found`. Itu wajar: workspace pertama adalah yang akan Anda
buat di langkah 1. Setelah itu ketiga perintah tersebut berjalan normal.

## Konsep singkat

Setiap service menulis log. Bila tiap service punya cara sendiri, log sulit dibaca
bersama. Karena itu satu paket `@ecommerce/logger` menyediakan:

- `createLogger(name)` — logger pino yang menulis **satu baris JSON per kejadian**,
  dengan field `service`, level dari `LOG_LEVEL`, dan data sensitif (header
  `authorization`, `cookie`, `password`) diganti `[REDACTED]`.
- `createHttpLogger(logger)` — middleware Express yang mencatat setiap request dan
  memberinya **correlation ID** (dipakai mulai m3.2).
- `CORRELATION_ID_HEADER` — nama header `x-correlation-id`, supaya tidak ada service
  yang salah ketik.

Paket bersama ditulis dalam TypeScript dan **dikompilasi** ke `dist/`. Service
memakai hasil kompilasi itu, karena Node tidak menjalankan `.ts` dari dalam
`node_modules`.

### Langkah 2 — Tulis `createLogger`

`packages/logger/src/index.ts`, bagian pertama:

```ts
import pino, { type Logger, type LoggerOptions } from 'pino';

export const CORRELATION_ID_HEADER = 'x-correlation-id';

export function createLogger(name: string): Logger {
  const options: LoggerOptions = {
    level: process.env.LOG_LEVEL || 'info',
    base: { service: name },
    redact: {
      paths: [
        'req.headers.authorization',
        'req.headers.cookie',
        'password',
        '*.password',
        'req.body.password',
      ],
      censor: '[REDACTED]',
    },
    timestamp: pino.stdTimeFunctions.isoTime,
  };
  if (process.env.LOG_PRETTY === 'true') {
    options.transport = { target: 'pino-pretty', options: { colorize: true } };
  }
  return pino(options);
}
```

Log yang rapi berwarna (`pino-pretty`) hanya aktif bila diminta lewat
`LOG_PRETTY=true`. Di container, log harus tetap JSON supaya bisa dibaca mesin.

### Langkah 3 — Tulis `createHttpLogger`

Masih di berkas yang sama:

```ts
import { pinoHttp, type HttpLogger } from 'pino-http';
import { randomUUID } from 'node:crypto';
import type { IncomingMessage, ServerResponse } from 'node:http';

export function createHttpLogger(logger: Logger): HttpLogger {
  return pinoHttp({
    logger,
    genReqId(req: IncomingMessage, res: ServerResponse) {
      const existing = req.headers[CORRELATION_ID_HEADER];
      const id = (Array.isArray(existing) ? existing[0] : existing) || randomUUID();
      res.setHeader(CORRELATION_ID_HEADER, id);
      return id;
    },
    customProps: (req) => ({ correlationId: req.id }),
    customLogLevel(_req, res, err) {
      if (err || res.statusCode >= 500) return 'error';
      if (res.statusCode >= 400) return 'warn';
      return 'info';
    },
  });
}

export type { Logger };
```

## Bila ada masalah

| Gejala                                                 | Solusi                                                                       |
| ------------------------------------------------------ | ---------------------------------------------------------------------------- |
| Log tidak berbentuk JSON                               | Hapus `LOG_PRETTY` dari environment; pretty-print hanya untuk mata manusia.  |
| Warna Tailwind tidak muncul                            | Pola `content` di `tailwind.config.js` harus mencakup `./src/**/*.{ts,tsx}`. |
| `Cannot find module '@ecommerce/logger'`               | Belum di-build. Jalankan `npm run build:packages`.                           |
| `build:packages` mengeluh soal `resilient-http-client` | Paket itu baru dibuat di m2.2; npm melewatinya.                              |
