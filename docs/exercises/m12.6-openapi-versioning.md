# m12.6 — OpenAPI dan Versi API `/api/v1` (OWASP API9)

| Branch awal                        | Kunci jawaban                       | Waktu     | Sebelumnya | Berikutnya |
| ---------------------------------- | ----------------------------------- | --------- | ---------- | ---------- |
| `starter/m12.6-openapi-versioning` | `solution/m12.6-openapi-versioning` | 120 menit | m12.5      | m12.7      |

## Yang akan Anda pelajari

- **OWASP API9 — Improper Inventory Management**: endpoint yang tidak tercatat adalah
  endpoint yang tidak diawasi.
- Membangkitkan spesifikasi OpenAPI 3.1 dari skema zod yang sama dengan yang memvalidasi request.
- Versi API di path (`/v1`) dan pensiun jalur lama yang diumumkan lewat header standar.

## Kondisi awal

- `scripts/openapi.mjs` belum mendokumentasikan detail, pembatalan, dan endpoint admin
  order. `services/gateway/openapi.json` dibangkitkan dari generator itu.
- `services/gateway/src/app.ts` hanya melayani jalur **tanpa** versi. Frontend sudah
  memanggil `/api/v1/...`, jadi UI tidak berfungsi sampai lab ini selesai.

```bash
git switch starter/m12.6-openapi-versioning
npm ci && npm run build:packages
npm test --workspace=services/gateway --workspace=services/order-service
```

Tes yang gagal:

- gateway (`tests/versioning.test.ts`): `routes /v1 to the same upstream paths without deprecation headers`,
  `keeps unversioned paths working, marked deprecated with a successor and sunset`,
  `serves aggregated health under /v1 as well as at the root`,
  `never forwards internal service routes, however the path is spelled`,
  `encodes the successor link so a request cannot inject Link parameters`,
  `serves the OpenAPI document it was built with`, `lists every route the gateway itself serves`
- gateway (`tests/gateway.test.ts`): `kebijakan CORS dan cache ditentukan gateway, bukan bawaan service di belakangnya` (memakai `/v1`)
- order-service (`tests/openapi-coverage.test.ts`): `documents every route the gateway exposes`

## Konsep singkat

| Path publik            | Perilaku                                                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `/api/v1/products`     | versi saat ini, tanpa header tambahan                                                                                       |
| `/api/products` (lama) | tetap berfungsi, ditambah `Deprecation: @<epoch>`, `Sunset: <tanggal>`, `Link: </api/v1/products>; rel="successor-version"` |
| `/api/v1/openapi.json` | dokumen OpenAPI, `Cache-Control: public, max-age=300`                                                                       |
| `/api/v1/health`       | sama dengan `/health`                                                                                                       |

nginx memotong prefix `/api` sebelum meneruskan ke gateway. Karena itu gateway tidak
melihat `/api`, dan header `Link` dibentuk dengan `config.api.publicPrefix`.

## Langkah-langkah

### Langkah 1 — Lengkapi spesifikasi

Di `scripts/openapi.mjs`, cari `TODO m12.6` dan tambahkan entri di objek `operations`
untuk: `/orders/{id}` (GET), `/orders/{id}/cancel` (POST), `/orders/admin` (GET),
`/orders/admin/summary` (GET), `/orders/admin/{id}` (GET),
`/orders/admin/{id}/fulfillment` (PATCH), `/orders/admin/{id}/cancel` (POST). Contoh
satu entri:

```js
'/orders/{id}': {
  parameters: [pathId],
  get: {
    operationId: 'getMyOrder',
    tags: ['orders'],
    summary: 'Detail order milik pemanggil (order orang lain: 404)',
    security: bearer,
    responses: { 200: json('OrderEnvelope'), ...errors(400, 401, 404) },
  },
},
```

Path Express `:id` ditulis `{id}` di OpenAPI. Lalu:

```bash
npm run openapi          # menulis services/gateway/openapi.json
npm run openapi:check    # generator + linter Redocly
```

### Langkah 2 — Prefix `/v1` di gateway

Ganti blok `TODO m12.6` di `app.ts`. Ingat untuk mengimpor `readFileSync` dari `node:fs`.

```ts
const openapi = readFileSync(new URL('../openapi.json', import.meta.url), 'utf8');
await app.register(
  async (v1) => {
    v1.get('/health', { config: { rateLimit: false } }, aggregatedHealth);
    v1.get('/openapi.json', async (_request, reply) =>
      reply.type('application/json').header('cache-control', 'public, max-age=300').send(openapi),
    );
    for (const route of routes) await v1.register(httpProxy, { ...route, ...proxyOptions });
  },
  { prefix: '/v1' },
);
```

### Langkah 3 — Jalur lama sebagai alias usang

Hanya bila `config.api.legacy.enabled`. Pasang hook **di dalam plugin terenkapsulasi**,
supaya header usang tidak ikut muncul di `/v1`:

```ts
const deprecation = `@${Math.floor(Date.parse(legacy.deprecatedAt) / 1000)}`; // RFC 9745
const sunset = new Date(legacy.sunset).toUTCString(); // RFC 8594
await app.register(async (unversioned) => {
  unversioned.addHook('onRequest', async (request, reply) => {
    const target = new URL(request.url, 'http://gateway.invalid'); // meng-encode > dan "
    reply
      .header('deprecation', deprecation)
      .header('sunset', sunset)
      .header(
        'link',
        `<${publicPrefix}/v1${target.pathname}${target.search}>; rel="successor-version"`,
      );
    request.log.info({ legacyPath: request.routeOptions.url }, 'jalur API tanpa versi');
  });
  for (const route of routes) await unversioned.register(httpProxy, { ...route, ...proxyOptions });
});
```

Mengapa lewat `new URL(...)`? Bila `request.url` mentah ditempel ke header `Link`,
klien bisa mengirim path berisi `>; rel="..."` dan menyisipkan parameter `Link` palsu.

## Bila ada masalah

| Gejala                                 | Solusi                                                                    |
| -------------------------------------- | ------------------------------------------------------------------------- |
| Tes cakupan gagal untuk route yang ada | Path `:id` harus ditulis `{id}` di OpenAPI.                               |
| `$ref` tidak ditemukan                 | Komponen harus terdaftar dengan nama yang sama di `responses`/`requests`. |
| Header usang muncul di `/v1`           | Hook dipasang di `app`, bukan di plugin `unversioned`.                    |
| `Link` menunjuk path tanpa `/api`      | Pakai `config.api.publicPrefix`; gateway tidak melihat prefix dari nginx. |
