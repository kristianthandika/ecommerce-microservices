# m12.6 — Inventaris API: OpenAPI dan versi `/api/v1` (OWASP API9) (Starter)

**Tujuan:** setiap endpoint publik tercatat dalam dokumen yang dapat dibaca mesin, dan jalur lama punya tanggal pensiun yang diumumkan.
**Yang perlu dibangun:** (1) di `scripts/openapi.mjs`, dokumentasikan endpoint detail, pembatalan, dan admin order (`/orders/{id}`, `/orders/{id}/cancel`, `/orders/admin/...`; starter hanya memuat daftar dan pembuatan order), lalu `npm run openapi`; (2) di `services/gateway/src/app.ts`, layani semua prefix di bawah `/v1`, sajikan `/v1/openapi.json` dan `/v1/health`, dan jadikan jalur tanpa versi alias dengan header `Deprecation` (RFC 9745), `Sunset` (RFC 8594), dan `Link: rel="successor-version"`.
**Acceptance:** `versioning.test.ts` (gateway) dan `openapi-coverage.test.ts` (order-service) lulus; `npm run openapi:check` lulus. Frontend di starter sudah memanggil `/api/v1`, jadi UI baru berfungsi setelah gateway selesai.

## Cara Debugging

- Tes cakupan gagal untuk route yang ada → path Express `:id` ditulis `{id}` di OpenAPI.
- `$ref` tidak ditemukan → komponen didaftarkan di registry zod dengan nama yang sama.
- Header deprecation muncul di `/v1` → pasang hook hanya di plugin Fastify terenkapsulasi untuk jalur lama.
- `Link` salah → gateway tidak melihat prefix `/api` yang dipotong nginx; pakai `config.api.publicPrefix`.
