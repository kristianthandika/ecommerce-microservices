# m2.2 — Resilient HTTP Client dari Nol (Starter)

**Tujuan:** memahami timeout/retry/circuit breaker dengan menulisnya sendiri (bukan library).
**Yang perlu dibangun:** `packages/resilient-http-client` — `withTimeout`, `withRetry` (exponential backoff + jitter), `withCircuitBreaker` (CLOSED→OPEN→HALF_OPEN→CLOSED), `createResilientClient` (komposisi), di atas native `fetch`.
**Acceptance:** unit test tiap wrapper terisolasi (timeout membatalkan; retry sesuai jumlah + delay membesar; breaker OPEN setelah threshold, tolak cepat, lalu HALF_OPEN).

## Cara Debugging

- Breaker tak pernah OPEN → state harus persist di closure (jangan dibuat ulang tiap panggilan).
- Retry tanpa jeda → pastikan delay benar-benar `await sleep(...)`.
