## Yang akan Anda pelajari

- Polling berkala dengan `useEffect` dan `setInterval`, lengkap dengan pembersihannya.
- Menampilkan status setiap service dengan warna brand (hijau = up, merah = down).
- Membuktikan perubahan UI dengan mematikan service sungguhan.

## Kondisi awal

Frontend dari m4.1: login, register, dashboard, dan `api.health()` di klien API.
Endpoint `/health` gateway dari m3.3 menjawab status semua service.

```bash
git switch starter/m4.2-health-widget
npm ci && npm run build:packages
```

## Konsep singkat

`useEffect` dengan dependency kosong (`[]`) berjalan sekali saat komponen tampil.
Fungsi yang dikembalikannya berjalan saat komponen hilang. Di situlah interval harus
dihentikan; tanpa itu, polling tetap berjalan di latar belakang setelah pengguna
pindah halaman.

```tsx
useEffect(() => {
  let active = true;
  async function tick() {
    const data = await api.health();
    if (active) setHealth(data);
  }
  tick(); // langsung sekali, jangan menunggu 3 detik pertama
  const id = setInterval(tick, 3000);
  return () => {
    active = false;
    clearInterval(id);
  };
}, []);
```

Variabel `active` mencegah `setState` pada komponen yang sudah tidak tampil, bila
jawaban datang terlambat.

## Langkah-langkah

### Langkah 1 — Komponen `frontend/src/components/HealthWidget.tsx`

1. State: `health: HealthResponse | null` dan `updatedAt: string`.
2. Pasang `useEffect` seperti di atas dengan `POLL_INTERVAL_MS = 3000`.
3. Judul "Status Layanan" dan lencana ringkasan: `Semua normal` bila
   `health.status === 'ok'`, `Ada gangguan` bila tidak, `Memuat…` sebelum data pertama.
4. Daftar baris: satu untuk `gateway`, lalu satu per kunci di `health.services`.
5. Setiap baris: nama service, titik berwarna, dan teks `UP`/`DOWN`. Warna diambil dari
   variabel CSS brand: `var(--color-success)` dan `var(--color-danger)`.
6. Teks kecil "Diperbarui otomatis tiap 3s · terakhir <jam>".

Titik warna diberi `aria-hidden`, karena teks `UP`/`DOWN` di sebelahnya sudah
menyampaikan informasi yang sama kepada pembaca layar. Jangan mengandalkan warna saja.

### Langkah 2 — Pasang di dashboard

Di `pages/DashboardPage.tsx`, impor `HealthWidget` dan tampilkan di samping atau di
atas katalog.

### Langkah 3 — Buktikan dengan mematikan service

```bash
npm run dev:all                       # terminal 1
npm run dev --workspace=frontend      # terminal 2
```

Login, lalu lihat widget: semuanya UP. Hentikan service satu per satu. Cara paling
mudah: jalankan keempat service di terminal terpisah
(`npm run dev --workspace=services/order-service`, dan seterusnya), lalu tekan
`Ctrl+C` di terminal order-service. Dalam kurang dari 3 detik baris `order` menjadi
DOWN dan lencana berubah menjadi "Ada gangguan". Jalankan lagi; widget kembali hijau.

Bila widget tidak berubah, periksa dulu gateway-nya: `curl -i localhost:8080/health`.
Bila gateway sudah menjawab 503 tetapi widget tetap hijau, masalahnya di widget.

## Bila ada masalah

| Gejala                              | Solusi                                                                                                                  |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Widget tidak pernah berubah         | Interval tidak berjalan, atau `api.health()` melempar error saat 503. `health` harus mengembalikan body 503 apa adanya. |
| Request `/health` berlipat ganda    | Di mode pengembangan React (`StrictMode`) effect dijalankan dua kali. Pastikan cleanup menghentikan interval pertama.   |
| Warning "state update on unmounted" | Variabel `active` belum diperiksa sebelum `setHealth`.                                                                  |
