# m4.2 — Live Service-Health Widget (Starter)

**Tujuan:** visualisasi status real-time.
**Yang perlu dibangun:** widget yang polling `/health` gateway tiap beberapa detik, menampilkan status tiap service dengan indikator warna brand (success/danger); pasang di Dashboard.
**Acceptance:** widget berubah saat satu service dimatikan (uji dengan mematikan service, verifikasi update dalam interval polling).

## Cara Debugging
- Widget tak update → cek interval polling jalan; uji `/health` gateway memang berubah saat service dimatikan (curl dulu sebelum curiga ke widget).
