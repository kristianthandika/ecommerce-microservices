# m2.3 — order-service dengan Chaos Test (Starter)

**Tujuan:** komunikasi antar-service tangguh + graceful degradation.
**Yang perlu dibangun:** Express app (pola m2.1), in-memory order store, panggil product-service via `resilient-http-client` (URL dari `PRODUCT_SERVICE_URL`), auth `jwks-rsa`, teruskan correlation id.
**Acceptance (3 skenario):** normal 201; product mati → order tetap merespons 503 graceful (bukan hang/crash); setelah breaker OPEN, panggilan ke product TIDAK bertambah linear. Test keluar bersih tanpa `--forceExit`.

## Cara Debugging
- Test menggantung → `await` `server.close()` di `afterAll` (promisify).
- Chaos tidak konsisten → tunggu threshold breaker tercapai sebelum assertion.
