# m2.1 — product-service & Distributed Auth (Starter)

**Tujuan:** verifikasi JWT tanpa memanggil auth-service tiap request.
**Yang perlu dibangun:** Express app (pola m1.2), in-memory product store, middleware verifikasi JWT via `jwks-rsa` (URL dari `AUTH_SERVICE_URL`, cache), RBAC (`GET` publik; `POST/PUT/DELETE` admin-only), validasi zod produk.
**Acceptance:** setelah panggilan pertama, mematikan auth-service TIDAK memengaruhi verifikasi berikutnya (dari cache); non-admin → 403; body invalid → 400.

## Cara Debugging

- `ECONNREFUSED` ke auth padahal jalan → jangan hardcode hostname Docker; pakai `AUTH_SERVICE_URL` (default localhost).
- JWKS ter-fetch tapi verifikasi gagal → cocokkan `kid` header JWT dengan `kid` di JWKS.
